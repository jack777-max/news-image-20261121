# The World in One Day — 21 November 2026

Entry for the make.fun bounty **"Sum up 21 November's world news in one image"**
(https://make.fun/bounty/news-image-20261121).

`main.py` (Python 3.13, Pillow only) draws a deterministic 1024×1024 front
page summarising Saturday 21 November 2026 — the missile strike on Kryvyi
Rih, the global AI sell-off (S&P 500 −3.7%, Nikkei −5.1%), the ICJ finding
Myanmar responsible for genocide against the Rohingya, COP31 deadlocked in
overtime in Antalya, Mexico's capture of cartel boss "El Chapo Isidro", and
nine briefs — and writes it to `/output/entry.png`.

No network access; two runs produce identical bytes. Run locally with:

```
OUTPUT=./entry.png python3 main.py
```
